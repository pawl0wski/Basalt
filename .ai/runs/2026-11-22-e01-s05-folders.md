# Run: E01-S05 rename, move and delete folders

## Goal

Implement `.ai/specs/implemented/2026-11-16-rename-move-delete-folders.md` (issue #39).

## What was done

- core: `renameFolder`, `moveFolder`, `deleteFolder` on `NoteOperations`; `rewriteRelativeLinks` takes an optional `remapTarget`; `createFolder` refuses a root `attachments`; new error details `flush-failed` and `folder-move-stopped`.
- app: notes actions flush the notes inside, mark them busy and follow path changes by prefix; tree store `remapPaths`/`prunePaths`; folder branches in tree actions (menu, rename dialog, delete confirmation, drag and drop with self/descendant refusal); `delete-folder` pending leave with retry, discard and cancel; the `reserved` name problem; texts and the `folder-move-stopped` description.
- ui: folder rows are draggable.
- Vitest at every layer, `e2e/folders.spec.ts`; `setupTests.ts` now stubs `Range.getClientRects` for jsdom.

## Decisions

- After a folder move, open notes inside are re-checked for external changes so the rewritten links reload into clean sessions instead of surfacing as a conflict.
- A stopped link rewrite after the directory moved still follows tabs and focus (the folder did move).
