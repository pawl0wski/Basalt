Toast proposals

Three directions. In every one the kind is named in words and has its own icon (never color alone), and the design stays within the Basalt tokens: no shadows, gradients or pills, two radii. Click a button to fire a real toast in the bottom right corner; hover a toast to pause its timer.

Fire as: Variant:

A · Labelled card

Small kind label with an icon above the title. Most readable, closest to today's layout.

  • Kind word always first
  • Fits long descriptions and actions
  • Timer line shows how long it stays

B · Compact line

One line: icon tile, "Kind · title", optional text action. Least intrusive over the editor.

  • About 44 px high
  • Good for frequent, passing results
  • Description wraps only when present

C · Header band

Mini window with a title strip: kind, time and close. Tool-like, with room for a technical detail.

  • Matches title bar and panels
  • Slot for an error code or path
  • Largest, so use for the important ones
