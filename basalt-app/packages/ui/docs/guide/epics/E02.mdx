Backlog: epic #6. Stories: E02-S01 (#11, connect to a server; its task #12 writes the sync and E2EE spec), E02-S02 (#13, encryption on the client), E02-S03 (#14, sync between devices).

## Expected screens once specified

These need a specification before they are designed: connecting to a server (address, status, errors), the encryption key or passphrase (the most sensitive screen, with no recovery promise unless the design has one), sync state per device and per note, conflicts between devices, and sync errors with actions. Components that will probably be reused: Dialog, Field, Alert, StatusIndicator, Card with rows, Tabs.
