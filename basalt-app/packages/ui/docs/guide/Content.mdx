# Content

How Basalt writes. The tone comes from the references: no exclamation marks, emoji or marketing text; one factual sentence under a setting; an empty place is a plain statement (R01.13, R01.14, W3). The words "sync", "E2EE" and "vault" are allowed because the users host their own server.

## Tone

**Basalt says:**

1. "No headings found." (R01.14, an empty panel)
2. "The folder is read-only. Choose a folder you can write to."
3. "Another program changed this file while you had unsaved edits. Saving is paused until you choose."

**Basalt does not say:**

1. "Oops! Something went wrong 😢" (exclamation mark, emoji, no information)
2. "Upgrade to Pro to unlock sync" (cloud-corporate, AB1)
3. "Your notes are in good hands ✨" (marketing language and a sparkle, A01)

## Buttons

- A verb and the object: "Save note", "Delete note", "Choose a workspace". Never "OK", "Yes" or "Submit".
- Sentence case, no final period, one to three words where possible.
- A button that opens another step may end with an ellipsis only if it asks for more input.

## Errors

- Say what happened and what the user can do: "Could not save the note. The folder is read-only. Choose a folder you can write to."
- Name the object when it helps: `Could not save "Weekly plan"`.
- Do not blame the user, do not show a bare code as the message. Technical detail goes in a code block below.

## Empty states

- Say why it is empty, then the next step: "Notes you create are saved as Markdown files in this folder." with a "New note" button.
- Two different empty cases get two different messages: nothing exists yet, nothing matches the filter.
- No illustrations, mascots or encouragement.

## Settings

- Under each setting, one factual sentence: what it does and what happens when it is changed (R01.13). Example: "Shown at the right of the status bar."

## Formats

| Thing | Rule | Source |
|---|---|---|
| Numbers | Thousands separator, English style: 1,204 words. | `StatusBar`; proposal for other numbers |
| Dates | Year-month-day (2026-10-18), as in the file names of the journal examples. | Proposal; no source defines it |
| Times | 24-hour clock. | Proposal; no source defines it |
| Currency | Not used: there is no payment in the product (AB1, N02). | Brief |
| File sizes | Binary units: 5 MiB, 20 MiB. | E01-S01, E01-S03 |
| Language | English only; no language switcher yet. | E01-S01 G10 |

Text goes in through props or the translation layer, so components never contain text that cannot be translated later.
