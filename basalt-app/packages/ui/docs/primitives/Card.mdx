# Card

## 1. What it is for

A card groups related settings under one heading, as one container with divided rows (R01.5), so the user sees which controls belong together.

<Canvas of={CardStories.Playground} />

## 2. When to use

- A group of settings in the settings view: "Status bar", "Appearance", "Workspace".
- A group of two or more rows, each with a title, optional description and one control.

## 3. When not to use

| Situation | Use instead |
|---|---|
| A single control. | The control in a Field, without a container. |
| A card inside a card. | One card with divided rows (R01.5, A01). |
| A message to the user. | [Alert](?path=/docs/primitives-alert--docs). |
| A list of notes. | The tree or list row, not a card. |
| Decoration or to make a screen look fuller. | Nothing. |

## 4. Anatomy

1. Heading (optional): `font-ui-strong` (600), `text-size-ui`, above the container (R01.5, tokens.md `font-weight-ui-strong`).
2. Container: `surface-card`, 1 px `border-divider`, `rounded-container` (8 px). No shadow.
3. Rows: separated by 1 px `border-divider` lines, padding `settings-card` (16 px).
4. Row content: title (`text-ui`), description (`text-size-ui-small`, `text-muted`), control at the right.

Title and description are 4 px apart (`gap-in-group`), rows are 16 px padded (R01.5).

## 5. Variants

One variant. `headingAs` sets the heading level (`h2` default, `h3`, `h4`) so the page outline stays correct.

<Controls of={CardStories.Playground} />

<Canvas of={CardStories.WithSelect} />

## 6. States

A card has no interactive state of its own; its controls do. Rows are not clickable. If a whole row must open something, use a [TextLink](?path=/docs/primitives-textlink--docs) or [Button](?path=/docs/primitives-button--docs) inside it.

| State | Notes |
|---|---|
| Default | The only state. |
| Hover, focus, pressed, selected, disabled, error, loading | Not applicable to the container. Show errors and loading in the rows' controls. |

## 7. Behavior and accessibility

- With a heading the card is a `section` named by that heading (`aria-labelledby`), so screen reader users can jump between groups.
- Without a heading it is a plain `section` without a name and is not announced as a landmark.
- Every control in a row needs its own accessible name. When the row title is the name, pass the same text as `aria-label` to the control.
- The row title is not a `label`: it does not move focus or toggle the control.
- Contrast: `text-ui` and `text-muted` on `surface-card` are at least 4.5:1 (measured in `contrast.test.ts`). Switches and checkboxes sit on `surface-card`, never on `surface-raised`.

## 8. Content

- Heading: a noun phrase, 1 to 3 words ("Status bar").
- Row title: what the control sets ("Word and character count"). Description: one sentence on the effect.
- Long titles and descriptions wrap; the control keeps its size and does not wrap.

<Canvas of={CardStories.LongText} />

## 9. Responsiveness

- 320 px: the control moves below the title and description.
- 768 px and above (`tablet:`): title and control share one line, the control right-aligned.
- Limit the card width with `max-w-prose` on wide screens.

<Canvas of={CardStories.NarrowScreen} />

## 10. API

`Card`:

| Prop | Type | Default | Description |
|---|---|---|---|
| `heading` | `ReactNode` | | Group heading. |
| `headingAs` | `"h2" \| "h3" \| "h4"` | `"h2"` | Heading level. |
| `children` | `ReactNode` | required | `CardRow` elements. |
| `className` | `string` | | Layout only. |

`CardRow`:

| Prop | Type | Default | Description |
|---|---|---|---|
| `title` | `ReactNode` | required | What the row controls. |
| `description` | `ReactNode` | | Effect or help. |
| `children` | `ReactNode` | | The control. |

## 11. Code

```tsx
import { Card, CardRow, Switch } from "@basalt/ui";

<Card heading="Status bar">
    <CardRow title="Word and character count" description="Shown at the right of the status bar.">
        <Switch aria-label="Word and character count" defaultChecked />
    </CardRow>
    <CardRow title="Sync status">
        <Switch aria-label="Sync status" defaultChecked />
    </CardRow>
</Card>
```
