# Select

## 1. What it is for

A select lets the user choose one value from a list of about 4 to 12 options, such as the interface text size.

<Canvas of={SelectStories.Playground} />

## 2. When to use

- One value from a known, short list that does not need search.
- A settings row where a list of radio buttons would take too much room.

## 3. When not to use

| Situation | Use instead |
|---|---|
| Two options. | Switch or [Checkbox](?path=/docs/primitives-checkbox--docs). |
| Three or fewer options the user should compare at once. | RadioGroup (Batch 3). |
| The user types to find an item. | A search field with results. It is not in the current plan; see "What is missing". |
| Free text. | [Input](?path=/docs/primitives-input--docs). |

## 4. Anatomy

1. Field box: same as [Input](?path=/docs/primitives-input--docs): 28 px, `rounded-control`, 1 px `border-control`, `surface-frame`.
2. Value text: `text-size-ui`, `text-ui`.
3. Chevron: 16 px `icon-default`, decorative, on the right.
4. Options: native `option` elements.

## 5. Variants

One variant. It is a styled native `select` (proposal, no new dependency). The open list is drawn by the operating system, so its look cannot follow the tokens. If the product needs searchable or styled lists, a Menu-based picker is built later from Batch 3 parts.

## 7. Behavior and accessibility

- Native `select`: role combobox/listbox, full keyboard support (arrows, type-ahead, Enter, Escape) and mobile pickers come from the platform.
- The name must come from a visible label (Field) or `aria-label`.
- Inside a Field it receives `id`, `aria-describedby`, `aria-invalid` and `aria-required`.
- Always preselect a real value or add an explicit placeholder option ("Choose a size") as the first option; do not leave the first option as an accidental default.
- Height 28 px (WCAG 2.5.8).

## 8. Content

- Option labels are short nouns or values, sentence case, no final period.
- Put the most common option first or order logically; do not sort alphabetically a list that has a natural order (small, large).
- A default that means "follow the system" is named "System default".

## 9. Responsiveness

The select fills its container; limit the container (`max-w-prose`). On touch devices the platform picker opens.

## 10. API

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `<option>` elements | required | The options. |
| `value`, `defaultValue`, `onChange` | native | | Same as a `select`. |
| `aria-invalid` | `boolean` | set by Field | Error style. |
| `disabled` | `boolean` | `false` | Blocks interaction. |
| ...rest | `SelectHTMLAttributes` | | Passed to the `select`. |

## 11. Code

```tsx
import { Field, Select } from "@basalt/ui";

<Field label="Interface text size" hint="Applies to menus and settings, not to notes.">
    <Select defaultValue="system">
        <option value="system">System default</option>
        <option value="small">Small</option>
        <option value="large">Large</option>
    </Select>
</Field>
```
