# Switch

## 1. What it is for

A switch turns a setting on or off and the change takes effect at once, for example "Sync notes between devices".

<Canvas of={SwitchStories.Playground} />

## 2. When to use

- A setting with two values that applies immediately, without a Save button: settings cards, the status bar options.
- The label can be read as "the thing is on or off".

## 3. When not to use

| Situation | Use instead |
|---|---|
| The value is saved later with a button, or is one of several options in a form. | [Checkbox](?path=/docs/primitives-checkbox--docs). |
| More than two values. | Select or RadioGroup. |
| An action, not a state. | [Button](?path=/docs/primitives-button--docs). |

## 4. Anatomy

1. Track: 36 x 20 px (`w-activity-button`, `h-activity-icon`), `rounded-switch` (the only pill shape, proposal in tokens.md). Off: `border-control`. On: `action-primary`.
2. Thumb: 16 px (`size-icon`), `text-on-accent`, 2 px from the track edge (`p-tab-indicator`). Moves 16 px when switched on.
3. Label: `text-size-ui`, to the right, required (as `label` or `aria-label`).

The track and thumb sizes reuse existing size tokens; a dedicated switch token is a proposal if the sizes need to drift.

## 5. Variants

One variant. The accent (`action-primary`) is used on switches (R01.2, tokens.md rule 6).

<Controls of={SwitchStories.Playground} />

## 6. States

<Canvas of={SwitchStories.States} />

| State | What the user sees | Notes |
|---|---|---|
| Off / On | Track color and thumb position. Position is the second signal next to color (WCAG 1.4.1). | |
| Hover | On: `action-primary-hover`. Off: no change. | Proposal. A lighter off track would not keep 3:1 with the thumb. |
| Focus | 2 px `focus-ring` outline, 2 px offset. | |
| Disabled | `state-selected` track, `text-muted` label. | Proposal (open question 3). |
| Loading | Not supported. If saving can fail, show the result with [StatusIndicator](?path=/docs/primitives-statusindicator--docs) or an Alert. | |

Switches never stand on `surface-raised`: `action-primary` on it is 2.80:1 (tokens.md rule 15). The thumb on the off track is 3:1 or better (measured in `contrast.test.ts`).

## 7. Behavior and accessibility

- A `button` with `role="switch"` and `aria-checked`. It is announced as "Sync notes between devices, switch, on".
- Keyboard: Tab to focus, Space or Enter toggles.
- The label wraps the control, so clicking the text toggles it.
- Inside a settings row where the title is shown by the row, pass `aria-label` with the same text instead of repeating it visually.
- `type="button"` by default: it never submits a form.
- Target: the whole row, at least 28 px high (WCAG 2.5.8).
- Without a built-in dependency: this component is written by hand (proposal); a Radix Switch can replace it later without changing the API.

## 8. Content

- Name the thing that is on or off: "Sync notes between devices", "Show word count". Do not write "Enable ..." or "On/Off" in the label.
- The label does not change when the state changes.
- Sentence case, no final period.

## 9. Responsiveness

The row wraps long labels and keeps its height. The switch stays on the same line as the first line of text on narrow screens.

## 10. API

| Prop | Type | Default | Description |
|---|---|---|---|
| `label` | `ReactNode` | | Visible label. Use `aria-label` if there is no visible label. |
| `checked` | `boolean` | | Controlled value. |
| `defaultChecked` | `boolean` | `false` | Initial value when uncontrolled. |
| `onCheckedChange` | `(checked: boolean) => void` | | Called with the requested value. |
| `disabled` | `boolean` | `false` | Blocks interaction. |
| `type` | `"button" \| "submit" \| "reset"` | `"button"` | Button type. |

## 11. Code

```tsx
import { Switch } from "@basalt/ui";

<Switch label="Sync notes between devices" checked={sync} onCheckedChange={setSync} />
```

```tsx
<CardRow title="Sync status" description="Shows Synced, Syncing or an error in words.">
    <Switch aria-label="Sync status" defaultChecked />
</CardRow>
```

## 12. Do and don't

    <DoDont
        good={{
            children: <Switch label="Sync notes between devices" defaultChecked />,
            reason: "The change applies at once, which is what a switch promises.",
        }}
        bad={{
            children: <Switch label="Enable sync (applies after Save)" defaultChecked />,
            reason: "A switch that waits for Save is a checkbox in disguise.",
        }}
    />

        bad={{
            children: <Switch label="Show word count" />,
            reason: "In a form, a switch suggests an immediate effect.",

</Unstyled>
