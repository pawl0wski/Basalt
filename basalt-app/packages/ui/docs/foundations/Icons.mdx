# Icons

Library: lucide (outline icons, one stroke width), as set in `components.json`. Tools are visible as icons in the header of their section; nothing is only under "···" or only on hover (R01.7, A02).

## Rules

| Rule | Source |
|---|---|
| Only single-colour outline icons, in the UI text colour. The colour changes only for the active state. | R02.4 |
| No emoji as icons, no coloured file-type icons, no sparkle icon for AI. | R02.4, A01, A02 |
| An icon without a visible label always has an accessible name (`aria-label`), and a tooltip shows it on hover and focus. The tooltip only repeats the name. | WCAG 4.1.2, 2.5.3 |
| Use an icon together with text when the meaning is not obvious or the action is destructive, for example "Delete note". | WCAG 1.1.1 |
| Decorative icons next to text are `aria-hidden`. | WCAG 1.1.1 |
| Icon buttons are 28 px, so the click target is at least 24 px. | WCAG 2.5.8 |
| A stroke width other than lucide's default is not specified in the materials, so the default is used everywhere. | proposal |
